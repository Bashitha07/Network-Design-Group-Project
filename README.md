\## 📊 Network Architecture Summary

\* \*\*Internet Gateway:\*\* SLT Fiber Business 100 (100 Mbps symmetric GPON via Cisco ISR4331 Router)\[cite: 9, 26]

\* \*\*Core / Distribution Layer:\*\* Cisco Catalyst 3650-24PS (Layer 3 Switches with PoE+ and OM3 Fiber inter-floor uplinks)\[cite: 12, 19]

\* \*\*Access Layer:\*\* Cisco Catalyst 2960-24TT and Ubiquiti switches\[cite: 19, 28]

\* \*\*Wireless Infrastructure:\*\* Cisco Aironet 1832i / Ubiquiti UniFi 6 Lite Access Points supporting IEEE 802.11ac Wave 2\[cite: 22, 29]

\* \*\*Power Protection:\*\* APC Smart-UPS (Line-interactive, pure sine wave backup for MDF and IDF)\[cite: 24]
