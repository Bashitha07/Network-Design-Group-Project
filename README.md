## Enterprise Profile
- **Organization**: Software Solutions (Pvt) Ltd
- **Location**: Colombo 03
- **Building**: Two-story commercial building
- **Floor Area**: 162 m² per floor
- **Capacity**: 41 wired devices and 60+ wireless clients [cite: 3, 4, 6, 22]

## Proposed Network Architecture
- **Internet Service**: SLT Fiber Business (100 Mbps symmetric GPON)
- **Core Routing**: Cisco ISR4331 Router
- **Distribution Layer**: Cisco Catalyst 3650-24PS Layer 3 switches with OM3 fiber uplinks
- **Access Layer**: Cisco Catalyst 2960-24TT access switches
- **Wireless**: Cisco Aironet 1832i Wi-Fi 5 access points
- **Power Protection**: APC Smart-UPS battery backups [cite: 9, 12, 19, 22, 24, 26]
